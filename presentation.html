Problématique

Comment garantir l’intégrité des données ?

  • Données sensibles manipulables
  • Archive ZIP = données + signatures
Les fichiers ZIP contiennent tout ce qu'il faut pour vérifier l'intégrité. C'est une architecture en "defense in depth" - plusieurs couches de vérification plutôt qu'une seule.

Objectifs

  • Vérifier intégrité données
  • Détecter altérations
  • Interface claire
L'objectif est de créer une interface web permettant à un contrôleur fiscal de vérifier rapidement l'intégrité des données sans avoir à comprendre la cryptographie.

Contraintes

  • Technologies imposées
  • Hors-ligne complet
  • 4-5 semaines

🔐 Architecture de Sécurité

Defense-in-depth : 3 niveaux indépendants

🛡️ Defense-in-Depth

  • Niveau 1: Chaînage
  • Niveau 2: Cryptographie
  • Niveau 3: API externe

Niveau 1: Chaînage

  • Enreg. N, référence sig. N-1
  • Détecte: suppressions, insertions, reordering
  • Ne détecte pas: modification contenu

Niveau 2: Cryptographie

  • Ed25519 (asymétrique)
  • JSON canonique (clés triées)
  • Détecte: toute modification contenu
