🛡️ Defense-in-Depth

  • Niveau 1: Chaînage
  • Niveau 2: Cryptographie
  • Niveau 3: API externe

🔗 Niveau 1: Chaînage

  • Enreg. N référence sig. N-1
  • Détecte: suppressions, insertions, réordering
  • Ne détecte pas: modification contenu

🔗 Chaînage - Exemple

  • sig_1 = H(data_1)
  • sig_2 = H(data_2 + sig_1) ← référence
  • sig_3 = H(data_3 + sig_2) ← référence

📝 Niveau 2: Cryptographie

  • Ed25519 (asymétrique, courbes elliptiques)
  • JSON canonique (clés triées)
  • Détecte: toute modification contenu

📝 Crypto - Processus

  • Reconstruire JSON stable
  • Importer clé PEM → WebCrypto
  • crypto.subtle.verify(signature)

📝 Crypto - Garanties

  • Intégrité (données non modifiées)
  • Authenticité (bon émetteur)
  • Non-répudiation (impossible nier)

🌐 Niveau 3: API (SAS)

  • Signature dans registre officiel ?
  • Confirme légitimité
  • Détecte: signature non officielle

🌐 API - Sécurité

  • HTTPS obligatoire
  • Timeout 5s (pas blocage infini)
  • Validation structure réponse

✅ 3 Niveaux = Robustesse

  • Chaînage → détecte suppressions
  • Crypto → détecte modifications
  • API → détecte non-officiel
